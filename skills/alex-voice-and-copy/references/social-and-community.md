# Social Media, Podcast & Community Copy (`social-and-community.md`)

Guidelines for writing X/Twitter threads, LinkedIn technical posts, YouTube descriptions, and CodingCat.dev Podcast show notes in `@alex.patterson`'s voice.

## 1. Platform Formatting Rules

| Platform | Hook Style | Structure | CTA Placement |
| :--- | :--- | :--- | :--- |
| **X / Twitter** | 1 punchy contrarian or practical insight sentence + 16:9 dark-mode Excalidraw image or short clip. | 3 to 5 posts max. Use a Markdown/text table or clear `✓` / `✗` lines in Post 2. Zero hashtags in the hook post. | Final post in thread with direct link to `codingcat.dev`. |
| **LinkedIn** | Concrete engineering lesson from building with Astro, Sanity, Cloudflare, or AI agents. | Short paragraphs (1 to 2 sentences), clear comparison breakdown, and a question for fellow engineers at the bottom. | Bottom of post or first comment with episode/tutorial link. |
| **YouTube Description** | First 2 lines repeat the core searchable promise for SEO before the "Show more" fold. | Timestamp chapters (`00:00`), links to GitHub repo, tools mentioned, and social links. | Top 3 lines + pinned comment. |
| **Podcast Show Notes** | Highlight the guest's expertise and the exact engineering problem solved in the episode. | Guest bio, 4-5 key takeaways, comparison table of tools discussed, and full chapter timestamps. | Subscribe links + sponsor callout box. |

## 2. Pre-Flight Checklist for All Social & Community Copy
- [ ] **Zero em-dashes**: Scan the entire draft to confirm not a single em-dash character is present.
- [ ] **No generic AI openers**: Never start with *"🚀 Thrilled to announce"*, *"Let's dive in!"*, *"In this thread 🧵"*, or *"Game-changer"*.
- [ ] **Concrete numbers & stack names**: Name specific versions and metrics (for example, `Astro 7 SSR`, `Sanity v6`, `Cloudflare D1`, `Hono`).
- [ ] **Visual pairing**: Every technical post should specify whether it pairs with a dark-mode Excalidraw diagram, a code screenshot, or a 16:9 AJ thumbnail.
